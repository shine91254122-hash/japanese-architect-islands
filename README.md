# 日本建築師島

一個不需安裝套件、可離線瀏覽的互動式單頁網站。內容聚焦 2006—2026 年間六位日本建築師與十八個代表案例。

## 開啟方式

直接雙擊 `index.html` 即可離線瀏覽。

若瀏覽器限制本機檔案，可在此資料夾開啟終端機並執行：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

再前往 `http://127.0.0.1:4173`。

## 內容與操作

- 六座可點擊的建築師島
- 十八個建築案例，包含前五位建築師各一個台灣案，以及伊東豊雄的一個日本案
- 建築師肖像、生平介紹與時間軸
- 清晨／黃昏場景、名牌與動畫開關
- 建築師、作品、材料關鍵字搜尋
- 手機、平板與桌面版響應式版面
- 所有必要圖片皆保存在 `assets/images`，斷網仍可使用

## 影像與資料

人物與建築照片來自 Wikimedia Commons，完整作者、授權與來源記錄於 `data/credits.json`。群島主視覺為本專案原創生成插畫，不代表任何實際建築。
